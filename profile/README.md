# Test Portal: open-source quality intelligence for engineering teams 

    • Unified QA context 
    • Real-time quality visibility 
    • AI-powered root cause analysis 
    • Data-driven release decisions 
    • Integration with your engineering ecosystem 

Test Portal is Vention’s open-source platform licensed under Apache 2.0 and free to use. Test Portal combines test management and automated test results analytics to provide a unified QA context. It gives engineering and QA teams real-time visibility into product quality, supports AI-powered root cause analysis, and provides quality data for more informed release decisions. 

Install and configure Test Portal independently using the resources in the repositories below, or make it part of a broader [AI Quality Engineering environment](https://ventionteams.com/ai/sdlc/quality-engineering). Vention can help adapt the platform to your QA workflows and connect it with AI agents and other engineering tools through MCP integrations.  

Test Portal is open to community contributions. Report an issue, suggest an improvement, or contribute code through the repositories.
